# vesel-health

> Vesel is a personal health assistant on the iPhone: it reads your band directly over Bluetooth, watches your sleep, recovery and stress in the background, and tells you when something isn't right, without your data going to anyone's cloud.

This folder is where everything about the project is written down. Read it and you should understand what it does and why, without opening the code. How these docs work: [CONVENTIONS](CONVENTIONS.md).
