# Security

Please report a security problem privately to hello@stojanovventures.com. Don't open a public issue for it.

In scope:
- The connection between the iPhone and the Mac (the certificate, the pin, the token, the set-up QR).
- Anything that could send health data off the phone and the owner's own Mac.
- The backup server in `server/` and the Vesel Backup Mac app.

This is a personal project: replies are best effort and there is no bounty.
